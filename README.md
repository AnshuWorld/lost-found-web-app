# Lost & Found App

A full-stack Lost and Found web application built using MERN stack technology.

## Tech Stack

- React
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt
- Axios

## Features

- User Signup
- User Login
- JWT Authentication
- Create Lost/Found Item
- View Items
- Update Own Item
- Delete Own Item
- Ownership Authorization

## Backend

```bash
cd server
npm install
npm run dev
